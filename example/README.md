# iranshahr example

A minimal example demonstrating how to render Bahraini and Azerbaijani licence plates using the `iranshahr` package and `plate_core`.

## Running the example

```bash
cd iranshahr/example
flutter run
```

The app displays several plate specs from both countries using different themes:

- **Bahrain civilian** (EU and US sizes)
- **Azerbaijan civilian** (car plate)
- **Azerbaijan transport** (motorcycle plate)

## About iranshahr

`iranshahr` provides plate specs, themes, and country blocks for:

- **Bahrain** — civilian, diplomatic, and police plate designs
- **Azerbaijan** — civilian, transport, diplomatic, and foreign-company plate designs

See the main `iranshahr` package README for more details.
