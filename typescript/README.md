## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/iranshahr/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/iranshahr';

const spec = country.specs.get('af.car');
console.log(country.package);
```

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
